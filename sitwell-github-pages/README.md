# SitWell GitHub Pages 网站

这是一个纯前端、无真实付款功能的 SitWell 模拟结账页。用户可以选择落座者、套餐、坐姿、附加服务和付款方式，并输入模拟信用卡信息。点击底部提交按钮后只会显示 `Success`，不会发送数据或执行支付。

## 发布到 GitHub Pages

1. 新建一个 GitHub 仓库，把本目录中的全部文件上传到仓库根目录。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **GitHub Actions**。
4. 推送到 `main` 分支后，工作流会自动发布网站。

网站无需安装依赖或运行构建命令。
